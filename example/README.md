# core_ads example

This example demonstrates the public `core_ads` API:

- placement definitions
- initialization
- banner and native widgets
- interstitial, rewarded, rewarded interstitial, and app open ads
- callbacks
- lifecycle observer
- clear APIs

Native ads require a platform native ad factory registered with the ID used by
`AdPlacement.nativeFactoryId`.

The sample uses Google test ad unit IDs.
